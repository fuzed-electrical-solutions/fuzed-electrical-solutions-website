# Fuzed Electrical Solutions

Fuzed Electrical Solutions website built with React, TypeScript, Vite, and Tailwind CSS.

## Getting Started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run test` - Run tests
